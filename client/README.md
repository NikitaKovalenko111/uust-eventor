# Eventor Mobile Client

React Native приложение (Expo + TypeScript) для студентов и модераторов мероприятий.

## Стек

- Expo (React Native)
- TypeScript
- Redux Toolkit
- redux-saga
- axios
- React Navigation (native stack)

## Структура

- src/components - переиспользуемые UI-компоненты
- src/pages - страницы приложения
- src/api/api.ts - все функции API
- src/redux/saga - saga-обработчики
- src/redux/slices - Redux slice-модули

## Реализовано

- Регистрация и авторизация
- Разделение ролей: пользователь и модератор
- ЛК пользователя: аватар, профиль, список моих мероприятий
- ЛК модератора: те же настройки + форма создания мероприятия
- Список мероприятий
- Поиск по всем полям + поиск по дате
- Страница мероприятия с фото, описанием и блоком обсуждения
- Простые анимации появления экранных блоков

## Запуск

1. Установить зависимости:
   npm install
2. Запустить:
   npm run start
3. Открыть в Expo Go на телефоне или эмуляторе.
